# OECT Capture：16 通道采集应用

本仓库用于公开分发 Windows 便携应用及使用文档。应用通过 USB 虚拟串口连接 STM32，接收两颗 ADS131M08 的 16 路采样数据，提供实时波形、原始数据保存、漏极电流换算及采集后频谱分析。

应用源码、MCU 固件和实验数据不在此仓库发布。

## 下载与启动

- [查看所有发行版本](https://github.com/w0jwj0w/OECT_Capture_Releases/releases)
- [v2026.1.0.19 下载页面](https://github.com/w0jwj0w/OECT_Capture_Releases/releases/tag/v2026.1.0.19)

当前应用为 **2026.1.0.19，正式发行**，配套 **MCU 2026.1.0.8**。已使用该固件的板卡无需因本次上位机更新重新烧录；旧固件或其他协议的设备不能直接替代。

1. 在发行页的 Assets 中下载 `OECT_Capture_portable_2026.1.0.19.zip`。
2. 将 ZIP **完整解压**到可写目录，保留 `_internal` 等子目录。不能只复制 EXE，也不要直接在压缩包内运行。
3. 运行 `OECT_Capture_2026.1.0.19.exe`，不需要另装 Python。
4. 连接板卡，点击“刷新串口”，选择对应的 USB 串口。

建议将程序和实验数据放在普通数据盘的独立目录；避免放进只读目录或 `Program Files`。当前便携构建面向 Windows x64，本仓库不提供 macOS、Linux 或 ARM 原生包。USB 串口驱动由系统和板卡环境决定，应用 ZIP 不包含驱动安装器。

| 手动量程配置 | 大、中、小三档按通道设置，支持应用到全部通道 |

| 测试备注 | 选择波形模板或填写纯文本，与本轮文件一起保存 |
| 频谱分析 | 全程汇总、分时窗口、多局部峰、频段选择、点击峰读数 |

| 软件更新 | 公开库检查、手动或可选自动下载、手动确认重启安装 |

## 第一次采集

### 1. 核对通道与硬件档位

通道从 **CH00** 开始编号；**CH09 是第 10 个通道**。勾选实际需要显示和保存换算值的通道。开始后通道选择和档位会锁定，避免同一次记录的列定义变化。

软件中的档位必须与对应通道的实际跳帽一致。选择档位只改变软件换算，**不会切换板上的硬件**。

| 软件档位 | 界面标称电流范围 | 名义有效采样电阻 | INA 名义增益 |
|---|---:|---:|---:|
| 大档 | 1～10 mA | 10 Ω | 5 |
| 中档 | 100 µA～1 mA | 100.9 Ω | 5 |
| 小档 | 10～100 µA | 1009.9 Ω | 5 |

这些参数针对配套板卡设计，不能直接用于不同前端。换算受 ADC 参考电压、PGA、实际电阻、前端增益和通道校准系数影响。默认零点为 0、增益修正为 1，尚未校准时不要把显示数值当作已经达到指定精度的电流测量。

### 2. 设置目录与测试信息

选择“数据目录”，点击“打开目录”可检查位置。默认是程序目录下的 `Data_capture`。

展开“测试信息”，选择脉冲、双脉冲、方波、正弦波、人体心电或数字心电，再点击“插入模板”。按短模板填写波形参数、Vgs/Vds 偏置和板卡版次与编号。双脉冲可分别填写两段脉宽及电平，并记录脉冲间隔。插入的内容可继续编辑，随本轮备注和采集目录保存。

向上或向下拖动测试信息栏下方的分隔条，可调整备注区高度。点击“通道与档位”可折叠通道设置。采集模式、输入频率、观察频带和 ADC 输入集中在同一行。

### 3. 开始、观察和停止

点击“开始采集”。每次启动程序后，首次同意手动档位确认即在本次运行中生效。软件在采集前核对 MCU 状态、固件版本及配置，异常时会阻止开始。

接收过程中可调整滚动窗口和显示量。点击“停止”后，等待串口停止确认及后台处理完成；自动保存时还会进行 BIN 转 CSV、频谱和图片导出。以状态提示为准，不要在后台处理尚未完成时关闭程序。

“输入频率”及“记录频率切换”仅记录用户输入的实验事件，不控制信号源，也不保证记录时刻等于模拟输入真正改变的时刻。

## 时域显示与采集模式

- 显示量可选择 ADC 原始码（LSB）、ADC 差分电压（V）、漏极电流（µA）。纵轴可能为负值，这是有符号测量结果，不能直接用数值增减代替电流绝对值增减。
- 短窗口在“原始/范围”模式下显示原始点；长窗口采用断开的最小/最大值包络减轻绘图负担。**不能从长窗口包络计数周期。** 查看周期时缩短窗口，并结合原始数据频谱。
- “低通 200/20/5 Hz”只影响显示，先滤波再进行显示降采样；不改变 BIN、CSV 或频谱输入。
- “恢复自动量程”用于手动拖动、缩放后恢复合适纵轴范围。
- 可选正常采集与显示、不绘图的解析模式或只保存原始 BIN 的模式，用于比较绘图和接收负载。不绘图模式不生成空白的时域截图。

原始接收在独立进程中运行。GUI 显示缓存拥塞时可能跳过过旧的**显示点**并断线，诊断记录中的 `gui_display_points_skipped` 与 BIN 序号缺帧是不同指标，不能混为一谈。

## 自动保存与“保存全部数据”

勾选“自动保存本次数据”时，停止后自动完成数据转换和导出，不需要先打开频谱窗口。

未勾选自动保存时，采集结果先临时保留为 BIN、配置、运行记录和备注，不立即转换 CSV 或计算频谱：

- 点击“查看频谱”：按需在后台生成频谱并打开窗口，但这不等于永久保存。
- 点击“保存全部数据”：直接使用主界面当前选定的数据目录，创建本轮子文件夹并完成转换、频谱和图片导出，**不会再次询问保存目录**。
- 先查看再保存会复用完整结果；附件不全时补算，失败会提示未全部完成。
- 尚未永久保存的临时记录在退出时会被清理。要保留实验，退出前务必完成“保存全部数据”。

每轮目录名形如 `20261104_203000`；同名时自动加后缀，避免覆盖。典型文件如下，具体以实际通道、模式和处理状态为准：

| 文件 | 用途 |
|---|---|
| `oect_时间.bin` | USB 原始字节，含 MCU 上传的完整 16 路帧；应优先归档 |
| `oect_时间.csv` | 已勾选通道的原始码、电压、档位及换算电流，以及帧/时间诊断列；电流数值列使用 A |
| `*_session.toml` | 本轮串口、通道、量程和校准配置快照 |
| `*_runtime.json` | 固件状态、序号/CRC/时间间隔、显示跳点、处理状态、备注等诊断信息 |
| `*_notes.txt` | 纯文本测试信息 |
| `*_time_domain.png` | 实际时域波形区域截图；自动保存取停止后画面，手动保存取点击时画面 |
| `*_spectrum.csv` | 全程汇总的完整频率格点及各通道幅度 |
| `*_spectrum_metadata.json` | 频谱时基、连续段等元数据 |
| `*_spectrum.png` | 全通道频谱图片，默认线性幅度 |
| `*_frequency_history.png` | 分时窗口局部谱峰轨迹图片 |
| `*_spectrum_peaks.csv` | 分时窗口局部谱峰数值表 |
| `*_time_spectrum.npz` | 分时窗口频率、幅度、起止时间及连续段等数组 |
| `*_spectrum_summary.html` | **全程各通道谱峰结论表**，浏览器可直接查看全部通道 |
| `*_spectrum_summary.txt` / `.csv` | 相同结论的文本及数值表 |

未勾选通道不进入实时换算和 CSV 通道列，原始 BIN 的固定帧仍保留全部通道。图片是显示或分析结果，不能替代 BIN、session 和诊断文件。

## 保存数据的检索目录

从v17起，每次自动或手动永久保存后，在所选数据目录的根目录生成`采集目录.html`。用浏览器打开，可按测试备注、时间、文件夹文字搜索，点击对应日期时间子文件夹查看本轮文件。

目录记录首次保存时间、对应文件夹、完整测试信息、保存状态和具体文件链接；同一子文件夹重试保存只更新一条记录，另存的新子文件夹分别记录。仅临时查看频谱不登记。已有历史目录不自动扫描，手动删除子文件夹后旧目录记录保留。

在软件菜单中打开“数据 → 采集目录”，点击 TXT、CSV、图片等链接会按 Windows 文件关联打开原文件，可以用原有软件编辑。再次打开目录时会读取备注 TXT 的当前内容。浏览器版 HTML 也包含文件链接，在下一次保存时刷新。

同级`采集目录.json`用于后续追加，请与HTML及数据子文件夹一起保留和移动；`.oect_capture_index.lock`用于防止多实例同时改写。目录更新失败会提示，原始数据不因此删除。目录功能仅在保存结束后工作，不读取BIN重算频谱。

## 频谱窗口使用方法

停止后点击“查看频谱”，窗口不会自动弹出。必要的后台计算完成后即可查看：

1. 选择“全程汇总”或一个分时分析窗口。
2. 使用 0～10 Hz、0～100 Hz、0～200 Hz、完整频带按钮，或修改频率上限。
3. 默认使用**线性幅度**，也可切换对数幅度查看弱分量；窗口手动导图遵循当前选择。
4. 初始打开“全部已选通道”，展示本次已选通道的频谱，默认0～200 Hz。总览可滚动，另保留每页最多4路的分页标签。拖动谱峰表下方的分隔条可增加表格高度。
5. 在谱峰附近点击，读取该通道原始 FFT 格点的频率（Hz）和峰值幅度（µA）；弱峰可先放大再选择。读数不做峰频插值。
6. 分时局部峰轨迹可选择通道、点击某个时间窗查看该窗频谱。点击“分时局部谱峰”标题可展开或折叠该区域。它表示窗口内局部峰，不是连续瞬时频率。
7. “打开全程谱峰结论”打开 HTML 汇总；每通道最多列出 8 个局部峰，按幅度排序，始终基于全程汇总，不随当前选中的分时窗口改变。

### 如何理解频谱

全程汇总采用去均值、线性去趋势、Hann 窗及重叠分段，按实际窗长加权汇总幅度平方后开方；它是**分段 RMS 幅度统计**，不是 Welch 功率谱密度，也不是对非平稳信号指定一个“真实基频”。

同一次实验中途切换输入频率时，全程汇总可能同时出现多个分量，其幅度受各频率持续时间和窗长影响；切换前后应分别查看分时窗口。很慢的 0.1 Hz 输入需要足够长的记录和分析窗口；短窗零填充只对齐频率格点，不增加真实分辨率。

最强谱峰可能来自输入、谐波、漂移、噪声或干扰，软件不自动把它认定为输入基频。显示滤波、抽点包络与原始 FFT 的输入不同，因此不能只凭屏幕外观认定频谱错误。

## 时间轴、采样率与数据有效性

配套固件的**名义采样率为每通道 3906.25 SPS**，名义奈奎斯特频率为 1953.125 Hz。选中 4 路并不把每路采样率除以 4。

当前 v2 协议每帧 80 字节，含 16 路采样、序号及 DRDY 逐帧计数。时间轴使用 MCU 记录的 DRDY 周期计数与其声明的计数器频率；FFT 使用通过间隔检查的连续片段。SEQ 缺口、ADC 无效帧、重同步及时间间隔异常会形成分析边界，软件不跨这些边界拼接或插值后称为原始数据。

界面“配置采样率”不是独立实测值；USB 平均收帧速度只作吞吐诊断，不用于自动校准时间或频率。MCU 声明时钟仍需独立校准，`DROP=0` 也不能单独证明全部 ADC 转换均已读取。

历史无时间戳的 v1 数据只能使用配置给出的名义时间尺度，不能据此恢复已经缺失的物理时间。上述限制不因软件设为“正式发行”而消失。

## 检查、下载和安装更新

打开“帮助 → 检查更新 / 更新设置”：

- 默认每次启动后，在空闲时检查一次**正式版**，可关闭自动检查。
- 更新地址为本公开仓库，正常检查和下载无需登录、无需令牌；令牌栏通常留空。
- 发现更高正式版本后，可以手动点击“下载更新”。也可开启“发现新版后自动下载”，默认关闭。
- 下载后检查 SHA256、ZIP 完整性、目录结构及安装清单。**自动下载不等于自动安装。**
- 无论下载方式如何，都必须手动点击“重启并安装”，并在确认框选择“是”，才会退出安装。
- 采集、保存、下载准备中或有未保存数据时阻止安装。开始采集/保存会取消正在进行的下载，采集优先。
- 安装在相邻的新版本目录，保留旧版；复制当前配置并继续使用原数据目录，不搬动实验数据。新版未完成启动确认时尝试重新打开旧版。
- 下次请从新版本目录启动；原快捷方式不会自动改到新版。MCU 固件不自动更新。

首次使用本更新流程 需要手动完整解压。v19为当前正式 Latest；软件不会把预发行当作正式版自动升级目标。若尚无正式版，使用发行页手动下载即可。网络错误、限流或无正式发行会提示检查未完成，不冒充“没有更新”。

更新缓存和安装结果位于 `%LOCALAPPDATA%\OECT_Capture\updates`。下载不支持断点续传，完整缓存会再次校验后复用；关闭时若仍在下载，会先取消并等待当前网络读取结束，单次网络等待超时为 10 秒。安装目录无写权限或空间不足时可保留旧版，通过发行页手动安装到可写目录。

## 常见问题

| 现象 | 首先检查 |
|---|---|
| 找不到串口 | 板卡供电、USB 数据线、Windows 设备管理器及串口驱动；关闭其他占用该串口的程序，再刷新 |
| 固件不匹配，不能开始 | 是否使用 MCU 2026.1.0.8；本仓库不提供固件，向板卡维护者取得配套版本 |
| 某路没有曲线或近似恒定 | 勾选状态、原始码/电压模式、自动量程、输入是否悬空或满量程，再检查接线；仅凭截图不能确定硬件或代码根因 |
| 电流幅度不对 | 通道档位、真实跳帽、参考电压、PGA、前端参数和校准系数；电流有正负号，注意区分数值与绝对值 |
| 时域像低频，频谱有高频峰 | 缩短显示窗口、关闭显示低通，检查是否在看包络；核对原始数据及信号源真正连接的输出通道 |
| 切频后全程峰不明显变化 | 全程是整次实验的统计，改看对应分时窗口；确认信号源的实际输出与连线 |
| 未自动保存时没有立即出现频谱 | 停止后点击“查看频谱”或“保存全部数据”，按需计算；查看不等于永久保存 |
| 保存后附件缺失 | 看状态栏及 runtime 的处理状态、错误，检查磁盘空间和权限，保留 BIN 并重试完整保存 |
| 接收时界面落后或卡顿 | 减少显示通道、缩短窗口，比较不绘图模式；分别检查显示跳点与 BIN/DRDY 连续性 |
| 更新检查提示 404 或没有正式版 | 先打开公开发行页；只有预发行时不会被正式版检查选中，不能因此判定下载库为私有 |
