`%LOCALAPPDATA%\Programs\OECT_Capture`，无需管理员权限；可更改位置。
两个版本使用同一套采集程序，安装器不参与数据接收及绘图。
安装版创建开始菜单入口，并可创建桌面快捷方式；在 Windows“已安装的应用”中卸载。

目录结构为 OECT_Capture/OECT_Capture_版本号，外层共享 Data_capture 和 Heartbeat_library。
安装版更新继续使用现有 ZIP 更新器，下载后仍须手动确认重启安装，
并同步开始菜单、桌面快捷方式和卸载显示版本。卸载程序存放于外层 .installer，
不会随版本目录替换而消失。

卸载只删除打包清单中的程序文件，保留实验数据、样本库、非程序文件及设置。
当前配置同时保存于外层 .settings/oect_capture_config.toml，重新安装时恢复；
系统中的应用偏好也保留。用户自行选择的外部或网络数据目录不被迁移或删除。
建议本机安装程序，按实验需要另外选择数据目录。

Setup 未配置代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示；
本版本未声称通过 Microsoft 信誉认证。仅从本项目正式发行页下载，并核对 SHA256。
便携版只需解压整个目录，不能仅拷贝 EXE。

本仓库用于公开分发 Windows 便携应用及使用文档。应用通过 USB 虚拟串口连接 STM32，接收两颗 ADS131M08 的 16 路采样数据，提供实时波形、原始数据保存、漏极电流换算及采集后频谱分析。

应用源码、MCU 固件和实验数据不在此仓库发布。

## 第一次采集

### 1. 核对通道与硬件档位

通道从 **CH00** 开始编号；**CH09 是第 10 个通道**。勾选实际需要显示和保存换算值的通道。开始后通道选择和档位会锁定，避免同一次记录的列定义变化。

软件中的档位必须与对应通道的实际跳帽一致。选择档位只改变软件换算，**不会切换板上的硬件**。

| 软件档位 | 界面标称电流范围 | 名义有效采样电阻 | INA 名义增益 |
|---|---:|---:|---:|
| 大档 | 1～10 mA | 10 Ω | 5 |
| 中档 | 100 µA～1 mA | 100.9 Ω | 5 |
| 小档 | 10～100 µA | 1009.9 Ω | 5 |

这些参数针对配套板卡设计，不能直接用于不同前端。换算受 ADC 参考电压、PGA、实际电阻、前端增益和通道校准系数影响。默认零点为 0、增益修正为 1，尚未校准时不要把显示数值当作已经达到指定精度的电流测量。

### 2. 设置目录与测试信息

普通启动时会弹出保存设置，可选择保存目录及是否自动保存、生成时域 CSV。取消弹窗会继续使用上次设置。“数据 → 启动时询问保存设置”控制该弹窗，也可随时通过“数据”菜单修改。

测试信息栏可选择空白文本、脉冲、双脉冲、方波、正弦波、人体心电或心跳回放。板卡版次及编号始终显示，右侧为“电解质及浓度”，所有模式共用；例如填写“第二版③号板”；电解质可填写“NaCl，0.1 mol/L”或“PBS，1×”，请自行注明单位，留空不会推定成分或浓度。填写内容随备注及已开启嵌入的图片、CSV、NPZ 等导出保存。选择波形模板后，只显示该模板的参数表单及 Vgs/Vds 偏置，填写后直接采集或保存，不需要追加或替换操作。未填项目保持为空，不自动推定实验条件。表单可填中英文、单位和特殊符号，保存原文；频谱自适应仅在正弦频率可解析为有限正数时启用。

选择“空白文本”时显示自由文本编辑框；其他模式可用“补充信息”按钮打开或关闭附加文本框，保存时自动附上板卡和电解质信息。切换模板会暂存各模板的参数和自由文本草稿；导出只使用当前选中的模式，自由文本作为补充信息追加到当前表单后，收起不会丢失或停止保存。“清空文本”保留板卡和电解质信息，可按 Ctrl+Z 撤销。自由文本右键菜单及顶部“测试 → 插入模板”均可切换模式。


通过“测试 → 显示测试信息”可收起备注区，拖动下方分隔条可调整高度。点击“通道与档位”可折叠通道设置。采集模式和 ADC 参数在“采集设置”中，滚动窗口在串口行，显示量和观察频带在“显示”中，频率切换记录在“测试”中。

### 3. 开始、观察和停止

点击右侧蓝色“开始采集”。采集启动后，同一按钮变为红色“停止采集”。每次启动程序后，首次同意手动档位确认即在本次运行中生效。软件在采集前核对 MCU 状态、固件版本及配置。

接收过程中可调整滚动窗口和显示量。点击“停止”后，等待串口停止确认及后台处理完成。自动保存会导出频谱、图片和已启用的时域 CSV。

“输入频率”及“记录频率切换”仅记录用户输入的实验事件，不控制信号源，也不保证记录时刻等于模拟输入真正改变的时刻。

## 时域显示与采集模式

- 显示量可选择 ADC 原始码（LSB）、ADC 差分电压（V）、漏极电流（µA）。纵轴可能为负值，这是有符号测量结果，不能直接用数值增减代替电流绝对值增减。
- 短窗口在“原始/范围”模式下显示原始点；长窗口采用断开的最小/最大值包络减轻绘图负担。**不能从长窗口包络计数周期。** 查看周期时缩短窗口，并结合原始数据频谱。
- “低通 200/20/5 Hz”只影响显示，先滤波再进行显示降采样；不改变 BIN、CSV 或频谱输入。
- “恢复自动量程”用于手动拖动、缩放后恢复合适纵轴范围。
- 普通启动默认显示漏极电流和测试信息。“显示 → 锁定时域和频谱视图”禁用图上的鼠标拖动和滚轮缩放。频谱窗中的“锁定视图”与主窗口同步，锁定时仍可点选谱峰和使用频段按钮。
- 可选正常采集与显示、不绘图的解析模式或只保存原始 BIN 的模式，用于比较绘图和接收负载。不绘图模式不生成空白的时域截图。

原始接收在独立进程中运行。GUI 显示缓存拥塞时可能跳过过旧的**显示点**并断线，诊断记录中的 `gui_display_points_skipped` 与 BIN 序号缺帧是不同指标，不能混为一谈。

## 自动保存与“保存全部数据”

在“数据”菜单中可以开关自动保存和从 BIN 生成时域 CSV。两项默认开启。关闭时域 CSV 后，自动或手动保存仍生成原始 BIN、频谱 CSV、频谱图片和测试记录。通过“采集设置 → 保存当前配置”可写入采集配置。

通过“显示 → 显示底部状态与接收统计”可隐藏主窗口底部两行。采集、保存或读取采集目录报错时，状态区会自动展开，本次提示保留在界面上，下次启动仍按原偏好显示。

“数据 → 在图片和数据中嵌入测试信息”默认开启，启动保存设置中也可切换。保存时域图和频谱图时，会在图下方添加完整备注，PNG 也包含 `test_notes` 文本元数据。CSV 保留原数值列并增加 `test_notes` 列，完整备注位于第一条记录，其余记录留空。备注含换行时使用标准 CSV 引号，Python 可直接使用 `csv.DictReader` 或 `pandas.read_csv` 读取。

NPZ 中的 `test_notes` 是 Unicode 标量，可用 `str(np.load(path, allow_pickle=False)['test_notes'])` 读取。频谱 JSON、会话 TOML 和全程谱峰结论也包含备注。原始 BIN 保持 MCU 字节流格式，配套 `_session.toml` 中的 `test_information.notes` 记录嵌入的测试信息。独立备注 TXT 与运行记录继续保留。

先查看频谱再保存，或修改备注后另存时，会复用数值分析结果并更新附注。关闭嵌入后再保存，可生成无附注图片及不含备注列的数据副本。

勾选“自动保存本次数据”时，停止后自动完成数据转换和导出，不需要先打开频谱窗口。

未勾选自动保存时，采集结果先临时保留为 BIN、配置、运行记录和备注。启用采集后自动打开频谱时，停止后会后台计算用于预览；关闭自动打开时按需计算。

- 点击“查看频谱”：按需在后台生成频谱并打开窗口，但这不等于永久保存。
- 点击“保存全部数据”：直接使用主界面当前选定的数据目录，创建本轮子文件夹并完成转换、频谱和图片导出，**不会再次询问保存目录**。
- 先查看再保存会复用完整结果；附件不全时补算，失败会提示未全部完成。
- 尚未永久保存的临时记录在退出时会被清理。要保留实验，退出前务必完成“保存全部数据”。

每轮目录名形如 `20261104_203000`；同名时自动加后缀，避免覆盖。典型文件如下，具体以实际通道、模式和处理状态为准：

| 文件 | 用途 |
|---|---|
| `oect_时间.bin` | USB 原始字节，含 MCU 上传的完整 16 路帧；应优先归档 |
| `oect_时间.csv` | 可选的时域 CSV，含已勾选通道的原始码、电压、档位、换算电流和帧诊断；电流列单位为 A |
| `*_session.toml` | 本轮串口、通道、量程和校准配置快照 |
| `*_runtime.json` | 固件状态、序号/CRC/时间间隔、显示跳点、处理状态、备注等诊断信息 |
| `*_notes.txt` | 纯文本测试信息 |
| `*_time_domain.png` | 实际时域波形区域截图；自动保存取停止后画面，手动保存取点击时画面 |
| `*_spectrum.csv` | 全程汇总的完整频率格点及各通道幅度 |
| `*_spectrum_metadata.json` | 频谱时基、连续段等元数据 |
| `*_spectrum.png` | 全通道频谱图片，默认线性幅度 |
| `*_time_spectrum.npz` | 分时窗口频率、幅度、起止时间及连续段等数组 |
| `*_spectrum_summary.html` | **全程各通道谱峰结论表**，浏览器可直接查看全部通道 |
| `*_spectrum_summary.txt` / `.csv` | 相同结论的文本及数值表 |

未勾选通道不进入实时换算和 CSV 通道列，原始 BIN 的固定帧仍保留全部通道。图片是显示或分析结果，不能替代 BIN、session 和诊断文件。

## 原始 BIN 格式与离线读取

上位机在采集时把 USB CDC 收到的原始字节按到达顺序写入 BIN。文件没有额外的容器头或文本表头。正常情况下是连续的二进制帧。也可能夹有协议文本、损坏字节或尾部半帧，独立读取时应搜索帧头并校验 CRC 后再接受记录。

配套 MCU 2026.1.0.8 使用协议 v2。每帧 80 字节，下表偏移从帧头的第一个字节起按 0 计数。

| 字节偏移 | 字段 | 编码 |
|---:|---|---|
| 0–1 | 同步字 | 固定十六进制 `A5 5A` |
| 2 | 协议版本 | `02` |
| 3 | 状态标志 | bit 0/1 为 ADC A/B CRC 通过，bit 2 为 DRDY 配对，bit 3 为时间可疑，bit 4 为新连续段 |
| 4–7 | 帧序号 SEQ | 小端 uint32 |
| 8–9、10–11 | ADC A、B 状态字 | 各为大端 uint16 |
| 12–59 | CH00 到 CH15 的 ADC 码 | 每通道 3 字节，大端 24 位二进制补码，CH00–07 来自 ADC A |
| 60–61 | MCU 自上次上报以来的丢帧数 | 小端 uint16 |
| 62–69 | DRDY 周期计数 | 小端 uint64 |
| 70–73 | MCU 声明的时间戳时钟频率 | 小端 uint32，Hz |
| 74–77 | ADC DRDY 事件序号 | 小端 uint32 |
| 78–79 | 传输帧 CRC | 大端 CRC-16/CCITT-FALSE，覆盖字节 0–77。多项式 `0x1021`，初值 `0xFFFF`，无反射，最终异或 `0x0000` |

旧协议 v1 的版本字节为 `01`，每帧 64 字节。偏移 0–61 的字段相同，CRC 在 62–63，无 DRDY 时间戳。

有源码环境时，可用内置命令从 BIN 补生成时域 CSV。下面在源码目录运行。替换路径时一并使用本轮 `_session.toml`，以便保留当时的量程与校准配置。

```powershell
python .\oect_capture.py --input "D:\实验\oect_20261106_140000.bin" --config "D:\实验\oect_20261106_140000_session.toml" --csv "D:\实验\oect_20261106_140000_decoded.csv"
```

自编 Python 数据处理时，可使用源码中的 `FrameParser` 和 `file_chunks` 流式读取。每个 `SampleFrame` 都含全部 16 个有符号原始码。

```python
from pathlib import Path
from oect_capture import FrameParser, file_chunks

parser = FrameParser()
for chunk in file_chunks(Path("oect_20261106_140000.bin")):
    for frame in parser.feed(chunk):
        # 示例只读取 CH09 的原始码，保留序号和时间戳供后续检查。
        seq, cycles, ch09 = frame.sequence, frame.timestamp_cycles, frame.channels[9]
```

物理量换算使用本轮配置。ADC 差分电压为 `raw × Vref / (PGA × 2^23)`。计算漏极电流还需应用对应通道的零点、增益修正、INA 增益和采样电阻。启用通道与量程等配置见 `_session.toml`，丢帧和有效性诊断见 `_runtime.json`。以 MCU 时钟计算 v2 段内相对时间时，用周期计数差除以该段的时钟频率。做 FFT 前按序号、有效性与时间间隔划分连续段。

## 保存数据的检索目录

从v17起，每次自动或手动永久保存后，在所选数据目录的根目录生成`采集目录.html`。用浏览器打开，可按测试备注、时间、文件夹文字搜索，点击对应日期时间子文件夹查看本轮文件。

目录记录首次保存时间、对应文件夹、完整测试信息、保存状态和具体文件链接；同一子文件夹重试保存只更新一条记录，另存的新子文件夹分别记录。仅临时查看频谱不登记。已有历史目录不自动扫描，手动删除子文件夹后旧目录记录保留。

在“数据 → 采集目录”中，目录在后台读取，每页显示 30 条。搜索使用索引中的备注、时间、文件夹和保存状态。页面显示该页备注 TXT 的最新内容。点击文件链接可用 Windows 关联程序编辑原文件。浏览器版 HTML 在下一次保存时刷新。

同级`采集目录.json`用于后续追加，请与HTML及数据子文件夹一起保留和移动；`.oect_capture_index.lock`用于防止多实例同时改写。目录更新失败会提示，原始数据不因此删除。目录功能仅在保存结束后工作，不读取BIN重算频谱。

## 频谱窗口使用方法

主界面右侧“查看频谱”位于采集按钮旁，滚动窗口在串口行直接调整。“显示 → 采集后自动打开频谱”默认开启，停止采集并完成后台处理后自动打开。未启用自动保存时，自动打开会在临时目录计算频谱，仍需“保存全部数据”永久保留。关闭该选项后可手动点击查看。

正弦波表单提供“频谱范围自适应”，默认开启并选择 10 次谐波，可改为 5 次或关闭。填写正弦波频率后，频谱上限按目标谐波频率再留 5% 余量，并限制在本次奈奎斯特频率内。仅正弦波模板使用此功能，其余模板保持原显示逻辑。

当前名义采样率 3906.25 SPS 的奈奎斯特上限为 1953.125 Hz。1000 Hz 输入的 5 次和 10 次谐波超出可观测范围，界面会提示这一限制。改变显示范围不改变 FFT 数值或采样率。查看频谱时可进行以下操作。

1. 选择“全程汇总”或一个分时分析窗口。
2. 使用 0～10 Hz、0～100 Hz、0～200 Hz、完整频带按钮，或修改频率上限。
3. 默认使用**线性幅度**，也可切换对数幅度查看弱分量；窗口手动导图遵循当前选择。
4. 初始打开“全部已选通道”，默认0～200 Hz，正弦波自适应启用时按目标谐波范围显示。总览可滚动，另保留每页最多4路的分页标签。拖动谱峰表下方的分隔条可增加表格高度。
5. 点击谱峰附近，图内标注和上方读数栏均显示频率（Hz）与峰值幅度（µA）。读数来自原始 FFT 格点。
6. 峰值表和“打开全程谱峰结论”均基于全程汇总。切换分析时间窗可查看对应频谱并点选峰值。

### 如何理解频谱

全程汇总采用去均值、线性去趋势、Hann 窗及重叠分段，按实际窗长加权汇总幅度平方后开方；它是**分段 RMS 幅度统计**，不是 Welch 功率谱密度，也不是对非平稳信号指定一个“真实基频”。

同一次实验中途切换输入频率时，全程汇总可能同时出现多个分量，其幅度受各频率持续时间和窗长影响；切换前后应分别查看分时窗口。很慢的 0.1 Hz 输入需要足够长的记录和分析窗口；短窗零填充只对齐频率格点，不增加真实分辨率。

最强谱峰可能来自输入、谐波、漂移、噪声或干扰，软件不自动把它认定为输入基频。显示滤波、抽点包络与原始 FFT 的输入不同，因此不能只凭屏幕外观认定频谱错误。

## 时间轴、采样率与数据有效性

配套固件的**名义采样率为每通道 3906.25 SPS**，名义奈奎斯特频率为 1953.125 Hz。选中 4 路并不把每路采样率除以 4。

当前 v2 协议每帧 80 字节，含 16 路采样、序号及 DRDY 逐帧计数。时间轴使用 MCU 记录的 DRDY 周期计数与其声明的计数器频率；FFT 使用通过间隔检查的连续片段。SEQ 缺口、ADC 无效帧、重同步及时间间隔异常会形成分析边界，软件不跨这些边界拼接或插值后称为原始数据。

界面“配置采样率”不是独立实测值；USB 平均收帧速度只作吞吐诊断，不用于自动校准时间或频率。MCU 声明时钟仍需独立校准，`DROP=0` 也不能单独证明全部 ADC 转换均已读取。

历史无时间戳的 v1 数据只能使用配置给出的名义时间尺度，不能据此恢复已经缺失的物理时间。上述限制不因软件设为“正式发行”而消失。

| 现象 | 首先检查 |
|---|---|
| 找不到串口 | 板卡供电、USB 数据线、Windows 设备管理器及串口驱动；关闭其他占用该串口的程序，再刷新 |

## 心跳回放（2026.3.0.1）

1. 测试信息选择“心跳回放”，点击“选择心跳与执行回放”（主界面开始采集按钮也可打开此模式）。进入独立试验窗口，常规采集/更新在试验进行中不可启动。
2. 选择自有外部样本库目录，内含 index.csv 及其 relative_file 指向的 NPY。程序不内置桌面路径或实验数据。加载索引后按数据集、train/test、原标签筛选，按页显示并多选加入队列，可上移/下移/移除。原标签不推定临床含义或真实心率。
3. ADC串口沿用主界面，另选DAC串口并查询能力。独立源需 HBST v1 / HEARTBEAT_DAC 固件；旧固定波形固件不能接收此协议。两串口不能相同。独立 DAC 固件仅在私有源码库发行附件提供，其他板卡需由用户核对后手动烧录；当前连接的心跳源板已按用户指示烧录验证。应用更新不会自动烧录，也不会升级 ADC 固件。
4. 默认 DAC0、0～2.3 V、360 点/秒、逐条独立、有效重复1、预热0、前基线/后恢复各0.5秒、待机0 V。执行参数必须为数字；备注表单不参与硬件定时。所有电压均为5 V名义满量程换码，未精密标定。固件限制0～3 V及100～1000点/秒，停止/完成均回待机电平，不提供无限正式试验。
5. 逐条模式每条单独装载并采集，一个trial目录；组合模式一次装载整个有序序列，超出HELLO容量明确拒绝，请减少选择或改为逐条。不会自动把暂停批次冒充连续序列。重复由计数器执行，不复制波形占RAM。
6. 逐心跳极值映射会去掉样本间绝对幅度差；统一缩放使用当前选择队列的共同极值。索引、来源、文件/数组SHA256、长度和有限值会检查，常数波形不能进行逐条极值映射。
7. 开始后先装载DAC，等待ADC进入有时间戳的采集，再执行前基线、源播放及后恢复。停止或断线保留部分数据，标记aborted/failed。源失去有效命令超过2秒时固件回待机，应用仍提示停止是否确认，不把ACK等同于实际电压回零。

保存根目录沿用主界面当前数据目录。本模式独立执行时始终保存原始试验，不依赖常规自动保存开关：

```text
Data_capture/日期时间/
  manifest.json
  trial_0001_样本ID/
    input.npy
    stimulus_u16.bin
    capture.bin
    trial.json
```

组合时 input_0001.npy、input_0002.npy 等按区段排列。input为原文件副本；stimulus为上传的小端uint16码；capture为原始ADC串口字节流（含可能的文本/坏帧，按帧头和CRC解析）。trial包含ADC换算配置、来源split/行号、码值/文件哈希、映射、各自时基、预热/有效重复、测试信息、源事件和ADC完整性。小型trial/manifest是必要元数据，不属于频谱派生文件。正常结束前核验BIN；没有CSV/图片不算保存失败。旧测试及旧数字心电文本不改写。

点击“对照分析已选试验”，或“重开trial文件夹”，可在删除外部样本库后重算。选择样本、重复（从0起，先预热）及启用的ADC通道，点击对照分析。共同频带按双方较低奈奎斯特频率限制；原值/目标V与响应µA保留独立单位，归一化叠加明确无单位。响应依照逐帧时间戳校验，不跨序号/CRC/时间异常拼FFT；连续有效点少于256会说明无法分析。

当前仅软件先后START与主机单调时钟估计对齐，没有共享硬件标记，不可从图上报告精确延迟/精确响应标签。数字目标不是实测DAC电压；两板时钟及实际电压均待硬件校准。分析不自动在trial目录生成CSV、PNG或NPZ。算法临时缓存完成后关闭，原始文件不改写。

对照窗口提供“导出当前对照（可选）”：主动选择目标目录后另建日期时间子文件夹，保存当前选择的输入/响应CSV、各自频谱CSV、对照PNG和估计对齐参数JSON。图片附测试信息；不改写原始trial，未点击不会生成这些附件。complete表示试验流程结束，ADC完整性问题另在integrity_warning和adc_integrity中记录，不能当作器件响应已验证。

本次实机边界：DAC新固件已烧录并通过串口、容量、有限回放、中止和失联停止；用户确认625 mV与row12波形正常。未给出精确电压/频率测值；ADC联合采集按用户要求未做，不报告OECT响应或精确延迟结果。
